## [0.7.0] — 2026-06-18

### Summary
Establishes developer governance and AI collaboration guardrails. Introduces a hard enforcement mechanism preventing AI agents from running git write commands, reorganises project documentation for team-wide clarity, and fixes stale references carried over from the Elasticsearch era.

---

### Added
- `scripts/guard-git-writes.sh` — PreToolUse hook script for Claude Code; blocks any Bash tool call containing git write commands (`commit`, `push`, `tag`, `merge`, `rebase`, `reset`, etc.) at the tool execution layer before they run
- `docs/DECISIONS.md` — renamed from `docs/lesson.md`; contains 7 project decisions and lessons derived from the CLAUDE.md accuracy audit; neutral name makes it useful to all developers, not just Claude Code users
- **Claude Code Setup section** in `CONTRIBUTING.md` — documents the one-time manual step to wire `guard-git-writes.sh` via `.claude/settings.json`; includes performance note and a skip instruction for non-Claude Code users
- **Postman collection link** in `README.md` — links to `postman_collection.json` at the project root from the API Reference section

---

### Changed
- `CLAUDE.md` — three updates:
  - Added one-line note at the top clarifying the file doubles as project coding standards for non-Claude developers
  - Updated `docs/lesson.md` reference → `docs/DECISIONS.md`
  - Added hard rule: no AI agent should run git write commands; suggestion-only policy
- `.gitignore` — added `.claude/settings.json`, `.claude/settings.local.json`, `.claude/hooks.reference.json` to keep personal Claude Code tool config out of the repository
- `.claude/settings.json` — wired `PreToolUse` hook to `scripts/guard-git-writes.sh`
- `CONTRIBUTING.md` — four updates:
  - Added Claude Code Setup section (hook config + performance note)
  - Updated Key Documents table: `docs/lesson.md` → `docs/DECISIONS.md`
  - Release Process step 4 now states "no AI agent should run git commands on your behalf" before the git command block
  - Removed stale note claiming `check-triage.sh` runs automatically via a Stop hook (hook was removed in v0.6.0)
- `README.md` — two fixes:
  - Architecture diagram: `# Elasticsearch documents` → `# OpenSearch documents`
  - Added Postman collection link under Swagger UI reference

### Migration Notes

No schema changes, no dependency changes, no API contract changes.

#### Claude Code users only
Create `.claude/settings.json` in the project root (gitignored — each developer does this once):

```json
{
  "permissions": {},
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Bash",
        "hooks": [
          {
            "type": "command",
            "command": "bash scripts/guard-git-writes.sh"
          }
        ]
      }
    ]
  }
}
```

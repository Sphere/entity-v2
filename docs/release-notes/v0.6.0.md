## [0.6.0] — 2026-06-16

### Summary
Completes the OpenSearch migration and restores the Spring Boot 3.4.2 + Java 21 baseline.
Patches three Tomcat CVEs. Establishes security policy, triage backlog, and developer tooling for the project.

---

### Security
- Patched CVE-2025-24813, CVE-2025-31651, CVE-2025-55754 via `<tomcat.version>10.1.36</tomcat.version>` in `pom.xml`
- Added `SECURITY.md` — security scope, 7 rules (dependency policy, secrets, input validation, DB safety, logging, error handling, OpenSearch), and security release notes
- Identified open security items: T-003 (`ddl-auto` default), T-005 (dead DB column), T-013 (OpenSearch empty credentials), T-014 (DB error message exposure)

---

### Added
- **Configurable CSV header-field-mappings** — `entity-sheet.header-field-mappings.*` in `application.properties`; maps CSV column headers to Java field names via config so renaming a sheet column requires no code change
- **Duplicate entry prevention** — `checkDuplicateSheetEntries` in `MasterEntityServiceImpl`; validates uploaded sheet rows against existing DB records before saving; throws `UploadEntityException` with conflicting codes on duplicate
- **Fuzzy phrase search** (`fuzzyPhraseSearchByName`) — typo-tolerant AND operator match combined with phrase boost (slop=2) for ranking exact phrase matches higher
- **Phrase search** (`phraseSearchByName`) — exact word-order match with slop=2 for minor reordering; supports multilingual queries
- **Dynamic filtered search** (`findEntitiesBySearchParameter`) — filters by `entityType` (fuzzy) and `languageCode` (exact term), with optional field-level strict or fuzzy query; controlled via `SearchDTO.strict`
- `SECURITY.md` — security policy document; referenced from `CLAUDE.md` for security-related work
- `docs/TRIAGE.md` — full issue backlog (T-001 to T-014) with severity, area, fix guidance, and status; security items tagged `[security]`
- `docs/AUDIT_NOTES.md` — historical record of the 8 CLAUDE.md vs codebase conflicts found this session
- `docs/RELEASE_NOTE_TEMPLATE.md` — standard structure for all future release notes
- `docs/release-notes/` — per-version release note files from v0.6.0 onwards
- `CONTRIBUTING.md` — developer guide: setup, scripts reference, release process, commit guidelines
- `CHANGELOG.md` — full version index from v0.1.0 (2026-02-03); links to release note files from v0.6.0
- `scripts/check-triage.sh` — verifies 11 automatable triage items against codebase; `--update` patches `docs/TRIAGE.md`
- `scripts/update-release-notes.sh` — drafts release note from `docs/RELEASE_NOTE_TEMPLATE.md` using git log; `--apply` writes `docs/release-notes/v{version}.md`
- `.claude/hooks.reference.json` — Stop and UserPromptSubmit hook configs preserved for future reference

### Known Issues

### Migration Notes

#### Environment Variables

| Variable | Change | Action Required |
|---|---|---|
| `ELASTICSEARCH_URIS` | Removed | Replace with `OPENSEARCH_URIS` |
| `ELASTICSEARCH_USERNAME` | Removed | Replace with `OPENSEARCH_USERNAME` |
| `ELASTICSEARCH_PASSWORD` | Removed | Replace with `OPENSEARCH_PASSWORD` |
| `OPENSEARCH_URIS` | Added | Default `http://localhost:9200` |
| `OPENSEARCH_USERNAME` | Added | **Must be set in production — do not leave empty** |
| `OPENSEARCH_PASSWORD` | Added | **Must be set in production — do not leave empty** |
| `OPENSEARCH_LOG_LEVEL` | Added | Default `WARN`; set `DEBUG` locally if needed |
| `JPA_DDL_AUTO` | Default unchanged | **Override to `validate` in all non-local environments** |

#### Database

No schema changes required for the OpenSearch migration.
The following is pending (T-005 — run when ready):

```sql
ALTER TABLE master_entities DROP COLUMN IF EXISTS additional_properties;
```

#### Config Changes

```properties
# Replace Elasticsearch config with OpenSearch:
opensearch.uris=${OPENSEARCH_URIS:http://localhost:9200}
opensearch.username=${OPENSEARCH_USERNAME:}
opensearch.password=${OPENSEARCH_PASSWORD:}

# Change ddl-auto default in production:
spring.jpa.hibernate.ddl-auto=${JPA_DDL_AUTO:validate}
```
